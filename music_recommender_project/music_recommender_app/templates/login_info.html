UWAGA — OGRANICZONY DOSTĘP

Ta aplikacja działa w trybie deweloperskim Spotify API.

Oznacza to, że logowanie przez OAuth jest możliwe wyłącznie dla kont jawnie dodanych do listy dozwolonych użytkowników w panelu Spotify Developers.

Tylko konto właściciela projektu jest uprawnione do zalogowania się.
Jeśli spróbujesz zalogować się na własne konto Spotify, Spotify odrzuci próbę autoryzacji.

NOTE — RESTRICTED ACCESS

This application runs in Spotify API development mode.

This means that OAuth login is only available to accounts explicitly added to the allowlist in the Spotify Developer dashboard.

Only the project owner's account is authorized to log in.
If you try to log in with your own Spotify account, Spotify will reject the authorization attempt.
